IF systolic_blood_pressure is outside 110–130 mmHg OR diastolic_blood_pressure is outside 75–85 mmHg, THEN trigger Red_Alert.
IF body_temperature ≥ 38°C, THEN trigger Red_Alert.
IF heart_rate is outside 60–100 bpm, THEN trigger Red_Alert.
IF measurement_timing == "preprandial" AND (blood_glucose < 70 mg/dL OR blood_glucose > 120 mg/dL), THEN trigger Red_Alert.
IF measurement_timing == "postprandial" AND blood_glucose > 180 mg/dL, THEN trigger Red_Alert.
IF fever_with_chills == True OR fever_with_sweating == True, THEN trigger Red_Alert.
IF breathing_difficulty == True OR breathing_with_sound == True, THEN trigger Red_Alert.
IF headache_intensity ≥ 6, THEN trigger Red_Alert.
IF swollen_locations_count ≥ 4 (out of legs, arms, face, hands), THEN trigger Red_Alert.
IF belly_pain_with_hard_abdomen == True OR belly_pain_with_bleeding == True, THEN trigger Red_Alert.
IF belly_pain_intensity > 6, THEN trigger Red_Alert.
IF loss_of_vaginal_fluid == True OR decreased_fetal_movement == True, THEN trigger Red_Alert.
IF diabetes_symptoms_count ≥ 4 (out of urine frequency, water intake, fatigue, sweating, nausea, vomiting, muscle stiffness, lightheadedness, fruity breath, fainting sensation, fainting), THEN trigger Red_Alert.
IF preeclampsia_symptoms_count ≥ 2, THEN trigger Yellow_Alert.
IF swollen_locations_count == 2 OR swollen_locations_count == 3, THEN trigger Yellow_Alert.
IF headache_symptoms == True AND headache_intensity < 6, THEN trigger Yellow_Alert.
IF vaginal_bleeding_intensity > 0, THEN trigger Yellow_Alert.
IF discomfort_during_urination == True (pain, burning, or bloody urine), THEN trigger Yellow_Alert.
IF belly_pain_symptoms_count ≥ 3 AND belly_pain_intensity < 6, THEN trigger Yellow_Alert.
IF diabetes_symptoms_count ≤ 3 (and greater than 0), THEN trigger Yellow_Alert.
IF blood_pressure is within 110\text{–}130 \mathbin{/} 75\text{–}85 \text{ mmHg}, AND body_temperature < 38°C, AND heart_rate is within 60–100 bpm, AND blood_glucose is within target limits, AND reported_symptoms_count == 0, THEN trigger Green_Alert (Informational Only).
IF Alert_Type == Red_Alert OR Alert_Type == Yellow_Alert, THEN transmit the alert data immediately to the physician dashboard AND send a real-time notification text/email to the responsible doctor.
IF Alert_Type == Red_Alert OR Alert_Type == Yellow_Alert, THEN hide the visual alarm indicator from the patient application screen AND display only localized medical advice/recommendations to minimize client anxiety.
IF patient_input_value falls outside safe programmatic boundaries (e.g., Temperature < 34°C or > 43°C), THEN reject the form submission AND prompt the user with contextual target-range validation text.
Maternal Age
IF age < 18, THEN set age_set = "Lower".
IF age ≥ 18 AND age ≤ 35, THEN set age_set = "Normal".
IF age > 35, THEN set age_set = "Higher".
Body Mass Index (BMI)
IF bmi < 19, THEN set bmi_set = "Lower".
IF bmi ≥ 19 AND bmi ≤ 25, THEN set bmi_set = "Normal".
IF bmi > 25, THEN set bmi_set = "Higher".
Inter-Pregnancy Interval
IF pregnancy_interval_years < 2, THEN set interval_set = "Lower".
IF pregnancy_interval_years ≥ 2 AND pregnancy_interval_years ≤ 10, THEN set interval_set = "Normal".
IF pregnancy_interval_years > 10, THEN set interval_set = "Higher".
Blood Pressure (BP) Boundaries
IF systolic_bp ≥ 70 AND systolic_bp < 90, THEN set systolic_set = "Low".
IF systolic_bp ≥ 90 AND systolic_bp ≤ 120, THEN set systolic_set = "Normal".
IF systolic_bp > 120, THEN set systolic_set = "High".
IF diastolic_bp ≥ 30 AND diastolic_bp < 50, THEN set diastolic_set = "Low".
IF diastolic_bp ≥ 50 AND diastolic_bp ≤ 90, THEN set diastolic_set = "Normal".
IF diastolic_bp > 90 AND diastolic_bp ≤ 120, THEN set diastolic_set = "High".
